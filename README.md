# The Operator's Framework (Viability Grid)
Description:
A Systems Engineering approach to evaluating independent income opportunities. This repository contains the logic for the "Viability Grid," a mechanical scoring system designed to filter out low-floor hustles and identify high-value, expert-tier work (e.g., RLHF, Technical Evaluation).

The Logic:
This system evaluates opportunities based on:

Time to First Dollar (TTFD)
Pay Ceiling
Entry Friction
Task Stability
Automation Risk
Usage:
See src/grid_logic.js for an example implementation of the scoring algorithm.
